محتويات الحزمة
================
1_Doctor_Models      : أسئلة الدكتورة (من ملف البنك المرسل) — PDF محلول + اختبار تفاعلي + ملف بيانات JSON
2_Extracted_Questions: أسئلة مستخرجة من المحاضرات بنفس الأسلوب — PDF + اختبار تفاعلي + ملف بيانات JSON
0_Earlier_Files      : الملفات الثلاثة السابقة (دليل المراجعة، الامتحان المحلول، الاختبار التفاعلي)

لإضافة نماذج جديدة: أرسل الملف وسأضيف أسئلته إلى قسم "نماذج الدكتورة" فقط، وأي أسئلة جديدة أستخرجها تذهب إلى قسم "المستخرجة" فقط.
ملفات HTML تعمل بدون إنترنت: نزّلها وافتحها من جهازك.
